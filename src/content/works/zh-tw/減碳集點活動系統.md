## 專案介紹

在團隊中擔任全端工程師，向學弟妹傳授開發經驗並帶領團隊完成校務系統協作計畫。

## 主要負責內容

- 規劃系統架構、撰寫規格文件、擬定報價，並與需求方溝通協調、釐清需求。
- 針對 Frontend、Backend 與 IaC（Infrastructure as Code）的 Pull Request 進行 Code Review。
- 重構 Frontend 與 Backend 既有程式碼，改善效能與程式可讀性。
- 調整既有校務系統 IaC 架構並改進 CI/CD 流程。
- 導入 SonarQube，協助團隊改善程式碼品質。
